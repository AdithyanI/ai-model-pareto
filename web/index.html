Two charts, one object

Intelligence, cost and speed get published as two separate scatter plots. They are two camera angles on the same three-dimensional object — so rotate it, and models that neither chart can show turn out to be among the best available.

Why a model can be best and still invisible

A model is worth considering when nothing else is at least as good on every axis you care about. On a flat chart that test only runs on two axes, so a model can be dropped for being slow by a chart that never priced it, and dropped for being expensive by a chart that never timed it. The two rivals that condemned it are different models, and neither beats it overall. Rotate to all three axes and it survives: those are the orange diamonds.

How to read it

Each point is one model configuration on one host, because price and speed belong to the host rather than the model. On a flat chart the green line is that chart’s frontier — the best intelligence you can get at each price, or at each response time. Everything in the shaded area is beaten by something on that line, so only the diamonds are marked.

Cost and time use logarithmic axes; the field spans orders of magnitude and a linear axis would crush everything cheap into the margin. Nothing is interpolated. The frontier is drawn as a staircase rather than a curve because the space between two models contains no models — only the guarantee that a bigger budget never buys you less.

Dominance is recomputed against whatever is currently on screen, so a point is never greyed out by a rival you have filtered away. The full method, including how the data is read and why this latency measure, is in the method note.
